```c
是靠提取对称位置的数字进行比对，还是利用数学性质？c语言确实可以拆字符串，但是没有运用数学性质那么方便和优雅
观察回文数的性质：123321 发现肉眼上的对称有点难转化成严谨的数学关系。于是换个方式思考：

直接设计一个把数字倒过来的函数 再和输入的数字匹配————
依次对百位 十位 个位取余？可怎么知道有几位呢？这是把思路限制在了“从左往右的阅读习惯上”，完全可以从右往左拆！
```

Q4
计算调和级数，输入x，输出前x项之和（准确的分数形式），如：【样例输入】10 【样例输出】7381/2520
```c
/*由于最终结果要是精准的分数形式，就不能直接做除法，而是通分再加起来
所以问题的关键在于求分母，即最小公倍数！先自己想象一个思路：
    拿最大的数n，依次求它的1倍，2倍...每求一次，就循环拿n除以1 2 3...只要有除不尽的就换下一个n的倍数。全部除尽就取该值
*/
# include <stdio.h>

long long LCM(int n){
    for (long long k=1;k>=1;k++){  //k是几倍的n
        for (long long i=1;i<=n;i++){  //依次拿kn去挨个除以1 2 3 4 5 ...(不要直接写kn了，是k*n！)
            long long q = k*n % i;
            if (q!=0)     //只要余数不为0就中断
                break;
            if (q==0 && i==n){         //能坚持除到第n项就暂停并返回值
                long long result=k*n;
                return result;       
            }    
        if (i == n)
            return result;
        }
    }
}

int main(){
    int n=0;
    scanf("%lld",&n);
    long long b=LCM(n);
    printf("%lld",b);
}
```

1. `save = 100 * ((rest-cost)%100);` 对100取余得到的是余数！比如213%100=13，这里会直接存1300 XD，应该直接做除法`save = ((rest-cost)/100)*100;` rest和cost都是整数，/100时会直接向下取整。
2. `printf("%d",rest*1.2);`这里不仅没有算上save的钱，而且乘以1.2之后会变成浮点数，%d调用会直接报错。可以写成`a + a/5`间接表示。或者`printf("%.0f",rest*1.2);`用.0f消去小数点。
3. `save = 100 * ((rest-cost)%100);`这里应该是+= 不然前面的白存了。
4. `if ((rest-cost)>100){`应该是`>=` 100元整也应该存
5. `for (int i=0 ; i<12 ; i++)` 月份应该从1算起
6. `save = 100 * ((rest-cost)%100);`
`rest -= save;   //save存完后，rest减去`这一步神了，直接拿累计的save去减了，是说怎么总是中止程序，原来直接减到负数了

对于一个五位数 $\overline{a_1a_2a_3a_4a_5}$，可将其拆分为三个子数：

$sub_1=\overline{a_1a_2a_3}$

$sub_2=\overline{a_2a_3a_4}$

$sub_3=\overline{a_3a_4a_5}$

例如，五位数 $20207$ 可以拆分成

$sub_1=202$

$sub_2=020\ (=20)$

$sub_3=207$

现在给定一个正整数 $K$，要求你编程求出 $10000$ 到 $30000$ 之间所有满足下述条件的五位数，条件是这些五位数的三个子数 $sub_1,sub_2,sub_3$ 都可被 $K$ 整除。

输出：每一行为一个满足条件的五位数，要求从小到大输出。不得重复输出或遗漏。如果无解，则输出 `No`。

```c
int main(){
```

**欢乐的跳**

一个 $n$ 个元素的整数数组，如果数组两个连续元素之间差的绝对值包括了 $[1,n-1]$ 之间的所有整数，则称之符合“欢乐的跳”，如数组 $\{1,4,2,3\}$ 符合“欢乐的跳”，因为差的绝对值分别为：$3,2,1$。

给定一个数组，你的任务是判断该数组是否符合“欢乐的跳”。

每组测试数据第一行以一个整数 $n(1 \le n \le 1000)$ 开始，接下来 $n$ 个空格隔开的在 $[-10^8,10^8]$ 之间的整数。

对于每组测试数据，输出一行若该数组符合“欢乐的跳”则输出 `Jolly`，否则输出 `Not jolly`。

初稿：
```c
//写一个取绝对值的函数，使用三目运算符————
//条件 ? 条件成立时的值 : 条件不成立时的值
int abs(i){
    return i<0 ? -i : i;
}

#include <stdio.h>
int main(){
    int a[n], b[n-1], c[n-1], d[n-1];//方括号里是个数！下标才减一

    for (int i=0; i<=n-1; i++){ 
        scanf("%d",&a[i]);
    }

//同时制造一个用来对比的递增数列（1到n-1）
    for (int i=0; i<=n-2; i++){

        int x = a[i];

        c[i] = abs(x-y);//c有n-1个元素，最大下标是n-2

    for (int i=1; i<=n-2; i++){ //进行n-2次操作

            int y = c[e+1];//下标不超过n-2

                z = x;
                x = y;
                y = z;

            d[e] = x;
            d[e+1] = y;
        }
```

1. `int a[n], b[n-1], c[n-1], d[n-1]`先要声明n这个整数并赋值，才能开始谈数组。int n;都不够，必须要有确定值。
2. `#include <stdio.h>` 放最上面！！！
3. `int abs(i){`函数的形式参数要写类型！`int abs(int i){`
4. 
```c

                z = x;

                y = z;

            d[e+1] = y;
```
这是“赋值”，存到新d数组的时候，e以1递增，会覆盖前一个！正确的冒泡排序应该是“交换”，且完全可以直接拿原来的c数组进行操作：
```c

                c[e] = c[e+1];

```
5. `b[n-1] == d[n-1]`只比较了第n-1个元素！要引入for循环！

```c
#include <stdio.h>
//写一个取绝对值的函数，使用三目运算符————
//条件 ? 条件成立时的值 : 条件不成立时的值
int abs(int i){
    return i<0 ? -i : i;
}

int main(){
    int n;
    scanf("%d",&n);//自动只输入第一个数
    int a[n], b[n-1], c[n-1];//方括号里是个数！下标才减一

//不知道要读入的个数,scanf不知道打几个空格 用for循环
    for (int i=0; i<=n-1; i++){ 
        scanf("%d",&a[i]); //n 已经被第一个 scanf 读走了！直接顺着读，没问题。
    }

//同时制造一个用来对比的递增数列（1到n-1）
    for (int i=0; i<=n-2; i++){ 
        b[i] = i + 1;//b有n-1个元素，最大下标是n-2
    }

//依次调用相邻两个数，做差取绝对值
    for (int i=0; i<=n-2; i++){
        int x = a[i];
        int y = a[i+1];
        c[i] = abs(x-y);//c有n-1个元素，最大下标是n-2
    }
    
//做差得到的是一个n-1乱序数组，使用冒泡排序
    for (int i=1; i<=n-2; i++){ //进行n-2次操作

        for(int e=0; e<=n-3; e++){ //依次取相邻2个元素
            if (c[e]>=c[e+1]){
                int hi = c[e];
                c[e] = c[e+1];
                c[e+1] = hi;
            }
        }
    }

    for(int i=0; i<n-1; i++){
        if ( b[i] != c[i] ){
            printf("Not jolly");
            break;
        }
        if ((b[i] == c[i]) && (i == n-2)){
            printf("Jolly");   
        }
    }
    
return 0;  
}
```
