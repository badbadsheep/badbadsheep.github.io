## 小节标题

普通段落。图片放 `images/`，附件放同一文件夹，正文都用相对路径引用（**下面是代码块，不是真图片**）：

```markdown
![](images/你的文件名.png)

[附件.zip](./附件.zip)
```
附件（zip / 音频 / 抓包）放同一个文件夹就行，构建时会被复制到线上同一路径。文件名别带空格 —— 粘贴插件会把空格写成 %20，图片检查会报找不到。
