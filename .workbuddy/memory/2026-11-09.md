## push.cmd 又崩：GitHub 连接重置 + PowerShell NativeCommandError
- 现象：`git fetch --quiet origin main 2>$null` 报 `Recv failure: Connection was reset`，PowerShell 5.1 抛 `NativeCommandError`，脚本在 `[4/4] 推送` 阶段终止。
- 现场：提交 `05ca1c5 更新：2026-11-09 12:59` 已成功、工作区干净；`origin/main` 仍是 `90c9ea2`，本地领先 1 个提交。curl github.com 一度 `000`/超时、无代理配置；稍后 `git ls-remote origin HEAD` 又恢复 exit 0 —— 典型间歇性网络抖动。
- 三重根因：
  1. 网络层 GitHub 不可达（非代码问题）。
  2. PowerShell 5.1 把被重定向的 native stderr（含 `2>$null`）包装成 `NativeCommandError`，全局 `$ErrorActionPreference='Stop'` 下直接终止脚本。实测：`2>$null` → 抛错；不重定向 → 正常；局部降级 `Continue` → 正常且 `$LASTEXITCODE` 可用。
  3. 逻辑坑：网络故障使 push 失败后，原脚本接着 `pull --rebase`，最终误报「有冲突需要手动解决」。
- 修复（全部在 `scripts/push.ps1`）：
  - 新增 `Invoke-GitQuiet`（局部降级 ErrorActionPreference，退出码写 `$script:GitExit`）、`Test-RemoteReachable`（`ls-remote origin HEAD`）、`Stop-Network`（网络诊断提示）。
  - 4 处 `2>$null` git 调用改用 `Invoke-GitQuiet`，只在函数内部保留一处受保护的 `2>$null`。
  - 第 4 步开头先探测远程；push / pull / 二次 push 失败时先判网络再谈冲突。
  - `Stop-Task` 文案去掉「没有提交、也没有推送」的绝对断言（提交可能已完成）。
  - `README.md` 报错表加网络条目。
- 验证：PowerShell 5.1 `Parser::ParseFile` 语法 0 错误；等价函数实测 `quiet_no_throw=yes git_exit=128`、`remote_reachable=True`、`branch=main`；BOM 保留、整文件 UTF-8 解码 OK。
- 没做：没有替用户 commit / push（外部动作）。网络恢复后重跑 `push.cmd` 即可；当前工作区只有 `M scripts/push.ps1` 与 `M README.md`，重跑会生成一个新 commit 再一并推送。

## 调研：VSCode 图文 Markdown → 飞书文档（重点图片迁移）
- 结论：飞书 Markdown 渲染只认 http(s) 外链 / 飞书内嵌 token，不认本地相对路径与 file://；直接传 .md 或复制粘贴必丢图。稳妥路径只有两条：
  - A（零账号、最稳）：预处理 → pandoc `--resource-path` 生成图片内嵌的 .docx → 飞书「上传 > 导入为在线文档」。官方导入 API 亦可：`drive/v1/medias/upload_all`(parent_type=ccm_import_open) → `import_tasks` → 轮询 `import_tasks/:ticket`；docx 上限 600MB，md/txt 20MB。
  - B（真·一键、原生块）：开源 `feishu-markdown-mcp`（VSCode `.vscode/mcp.json` + npx），本地相对图片自动上传，`FEISHU_USER_MOBILE` 可自动转交文档所有权，解决 tenant_access_token 文档归属坑。需自建应用权限 `docx:document` + `docs:document.media:upload`。
- 本项目特有坑（两条路线都必须先做「清洗层」）：正文有 `<div class="figures" w-30>` / `<div class="figures w-45>` 这类 raw HTML 包裹的图片，通用 md 解析器/pandoc 会整块丢弃；另有 front matter、`==高亮==`。清洗需：剥 front matter 补标题、展开 div 并映射 w-XX → 宽度、按 `scripts/check-images.mjs` 现有规则把图片相对路径改绝对并校验存在、`==xx==` 降级粗体。
- 图片资产现状：`src/assets/images` 83 png + 1 gif，无 webp/svg（安全）；gif 到飞书可能只剩首帧。
- 成本：飞书免费版 0 元（15GB / 认证 100GB），个人账号可建「一人企业」自建应用，自建应用 API 免费 10,000 次/月；pandoc 与 MCP 工具均免费开源。API 路线额外一次性成本：应用发布 + 文件夹授权（tenant_access_token 需把文件夹分享给含应用机器人的群）。
- 排除：md-lark-converter（Ctrl+Shift+L 复制粘贴，但只保留图片链接、不上传本地图）、图床外链、直接上传 .md。
