## 评论不显示 + 手机端正文贴左（已推送 ca8fc6d）

- 评论空壳的真因：`.env` 不进仓库，CI 只读仓库 Variables（从没建过），
  所以线上构建出来是 `configured=false`，渲染成"评论区还没接上"的说明。
  修法：`src/components/comments/Giscus.astro` 内置四个公开 ID 作兜底，
  env 仍优先。已验证线上 HTML 带 `data-giscus`，giscus API 正常返回 categories。
- 手机端贴左的真因：`body:has(.toc-panel) .page--wide` 权重高于小屏媒体查询里的
  `.page--wide{margin-inline:auto}`，目录虽然 `display:none`，`margin-right` 仍算
  16rem，盒子过约束 → 左边距被压成 0。修法：把那条规则包进 `@media (min-width:62rem)`。
